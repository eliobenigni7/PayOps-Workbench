# 90-second Demo Script

## 0–15s — Problem

"A payroll team should not spend the same attention on every record. This batch has 1,284 records; deterministic validation automatically clears 1,191 and sends 93 to review."

## 15–35s — Prioritization

Open Review Queue.

"The remaining cases are ranked by an interpretable score. Critical cases are not just labelled critical — the app can explain the exact contributions."

Open salary anomaly.

## 35–55s — Investigation

"This employee's gross salary increased 42% and there is no corresponding HR change event. The AI copilot can summarize the evidence and suggest what to verify, but it cannot approve or resolve anything."

## 55–70s — Resolution

Mark as expected -> Salary increase.

"The operator owns the decision and records a structured reason, so the system learns operationally without pretending the model is an authority."

## 70–90s — Operations Excellence loop

Open Insights.

"The real value appears over time: recurring exceptions reveal the process bottlenecks. Missing bank information accounts for 4.9 hours of review per month, so the tool proposes an upstream onboarding validation. The goal isn't a smarter queue forever; it's to shrink the queue by fixing the process."
