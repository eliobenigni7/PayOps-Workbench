# Metrics

## Batch metrics

- processed records;
- auto-clear count / rate;
- review count / rate;
- critical count / rate;
- failed-evaluation count.

## Review metrics

- average time to first review;
- average handling time;
- queue age;
- resolution mix;
- escalations;
- reopened cases.

## Rule-quality metrics

- trigger frequency;
- confirmed-issue rate;
- false-positive rate;
- average handling time when triggered;
- overlap with other rules.

## Operations Excellence metrics

- estimated baseline manual review time;
- actual triaged review time;
- estimated effort avoided;
- recurring issue volume;
- effort associated with recurring issues;
- estimated effort removable via upstream change.

## Important caveat

Time-saved and ROI numbers in the portfolio demo are scenario assumptions. Display the methodology and assumptions; do not present them as measured Jet HR outcomes.
